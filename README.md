### Описание

* Обход DPI: предотвращение замедления и блокировок популярных интернет-сервисов.
* Написан на Python: простая кодовая база и минимальное потребление ресурсов.
* Адаптация под РФ: оптимизирован для обхода актуальных методов фильтрации трафика.
